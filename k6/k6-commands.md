## ps1 파일 실행 방법
터미널에서 실행하며 현재 디렉토리 위치를 루트에서 수행해야함
```powershell
.\k6\scripts\디렉토리명\파일명.ps1
```


### 1. Schedule
```powershell
.\k6\scripts\schedule\run-all-schedules.ps1
.\k6\scripts\schedule\run-schedule-detail.ps1
```


### 2. Travel
```powershell
.\k6\scripts\travel\run-popular-schedules.ps1
```
